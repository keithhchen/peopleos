# PeopleOS

A relationship advisor that runs in your terminal via Claude Code.

## Setup

```bash
npm install -g @anthropic-ai/claude-code
git clone https://github.com/keithhchen/peopleos.git
cd peopleos
claude
```

## What it does

Helps you think through relationships — not by giving quick answers, but by helping you understand the people and dynamics involved.

All data stays local.
